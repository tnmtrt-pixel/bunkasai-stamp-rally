# 文化祭デジタルパンフレット

文化祭のデジタルパンフレットです。出し物の紹介、会場マップ、ステージ、スタンプラリー（教室9か所）が入っています。

- `index.html` パンフレット本体（ホーム・出し物・マップ・スタンプ）
- `festival.js` 表紙・ステージ・お知らせの内容（文化祭の名前や日時はここ）
- `display.html` 各教室に置く画面（30秒ごとに変わるQRコードを表示）
- `config.js` 教室名などの設定

各教室の画面を開くには係用番号が必要です。

`map.png` は会場マップです。台紙ページの「マップ」タブに表示されます。

`shops.js` は「出し物」タブの紹介文・メニューです。各出し物の `desc`（紹介文）、`menu`（品名と値段）、`note`（時間や注意）を書き換えると反映されます。

`cover.jpg` は表紙、`stub.jpg` は入場チケットの切り取り部分です。初めて開いたときに、チケットをスワイプで切る演出が出ます。

スタンプは教室9か所のうち5か所（`festival.js` の `rallyGoal`）で景品と交換できます。教室の画面（display.html）のQRは、係が「QRを表示する」を押したときだけ20秒間（`config.js` の `reveal`）表示されます。
